第一章

初到荒野

新手引导阶段，学习基础操作

★

任务1：踏上旅途

主线
🎯 报酬：320 ZENY⏱️ 限时：50分钟📍 地点：绿荫平原

📋 流程步骤

  1. 出发准备

    在营地与艾莉交谈接受任务。检查装备，携带足够的治疗药和食物。推荐武器：大剑。

  2. 前往调查点

    沿标记路线前进，途中教授基本移动、攻击和防御操作。

  3. 首次遭遇

    遇到第一只目标怪物——林西刃爪。这是教学战，怪物攻击力较低。

  4. 完成任务

    击败怪物后返回营地，获得首笔报酬和初始装备。解锁营地系统。

💡 攻略提示

  • 不要急于进攻，先观察怪物的攻击前摇动作
  • 闪避时按住方向键可以改变闪避方向
  • 第一次击杀后会获得斩击斧的制作材料
★

任务2：牙猎犬的羁绊

主线
🎯 报酬：450 ZENY⏱️ 限时：50分钟📍 地点：绿荫平原·北部

📋 流程步骤

  1. 寻找牙猎犬

    在营地附近找到受伤的牙猎犬，使用治疗药为其疗伤。

  2. 追踪训练

    牙猎犬会教你追踪技能。按住互动键让它嗅探附近的怪物踪迹。

  3. 合作狩猎

    与牙猎犬一起讨伐草食龙。牙猎犬会自动攻击怪物。

💡 攻略提示

  • 牙猎犬可以抢夺怪物掉落物，战斗中注意站位
  • 完成此任务后解锁炼金系统
★★

任务3：林西刃爪的威胁

主线
🎯 报酬：680 ZENY⏱️ 限时：50分钟📍 地点：绿荫平原·森林深处

📋 流程步骤

  1. 情报收集

    在营地查看任务信息，了解林西刃爪的活动范围。

  2. 设置前进营地

    在靠近怪物栖息地的位置设置前进营地。

  3. 狩猎开始

    林西刃爪是敏捷型怪物，擅长快速连击和突袭。

  4. 弱点打击

    林西刃爪的前肢和头部是弱点部位。

🐾 怪物聚焦：林西刃爪

属性弱点雷 ⚡ → 火 🔥
高伤害部位头部、前肢
可破坏部位左前肢
特殊掉落林西刃爪甲、林西刃爪爪
第二章

灼热的考验

进入沙漠区域，解锁牙猎龙骑乘系统

★★

任务4：沙漠中的阴影

主线
🎯 报酬：850 ZENY⏱️ 限时：50分钟📍 地点：灼热沙漠

📋 流程步骤

  1. 适应高温

    进入沙漠后注意温度计量表，需饮用清凉饮料或使用降温炼金。

  2. 探索沙丘

    在沙丘间寻找怪物踪迹，沙地下有沙海龙出没的信号。

  3. 遭遇沙海龙

    沙海龙会潜入沙中突袭，注意地面震动波纹，使用音爆弹逼它现身。

💡 攻略提示

  • 沙漠区域有热浪扭曲效果，远距离攻击会有偏差
  • 夜晚沙漠温度骤降，需要保暖措施
★★★

任务5：牙猎龙的觉醒

主线
🎯 报酬：1200 ZENY⏱️ 限时：50分钟📍 地点：灼热沙漠·绿洲

📋 流程步骤

  1. 发现幼龙

    在沙漠深处的绿洲发现一只被困的幼年牙猎龙。

  2. 解除封印

    击败守护绿洲的熔岩龙幼体，解除牙猎龙的封印。

  3. 骑乘训练

    解锁牙猎龙骑乘系统，可以空中飞行、俯冲攻击。

💡 攻略提示

  • 牙猎龙骑乘有耐力限制，合理使用
  • 骑乘状态下可以对怪物造成大量硬直
第三章

苍蓝的召唤

探索海域，揭开古代文明的秘密

★★★

任务6：深海之谜

主线
🎯 报酬：1500 ZENY⏱️ 限时：50分钟📍 地点：苍蓝海域

📋 流程步骤

  1. 抵达港口

    乘坐船只到达海边据点，从这里开始可以进入海域探索。

  2. 潜水装备

    领取潜水装备，可以长时间在水下活动。注意氧气量。

  3. 海底遗迹

    探索海底古代遗迹，里面有珍贵的炼金素材和古代文献。

  4. 遭遇海龙

    在遗迹深处遭遇苍海龙，需要利用地形和水下机动性来战斗。

🐾 怪物聚焦：苍海龙

属性弱点雷 ⚡ → 冰 ❄️
高伤害部位头部、鳍
特殊能力水遁、漩涡
关键素材苍海龙逆鳞、海龙水晶
第四章

烈焰的试炼

深入火山地带，挑战最严酷的环境

★★★★

任务7：熔岩之路

主线
🎯 报酬：2000 ZENY⏱️ 限时：50分钟📍 地点：火山地带

📋 流程步骤

  1. 耐高温准备

    火山区域有持续高温伤害，必须装备防火防具或服用耐热炼金。

  2. 穿越熔岩

    地图中有流动的熔岩河，需要踩着岩石跳跃前进。

  3. 火山爆发

    任务中途会触发火山爆发事件，需要在限定时间内逃离。

  4. 炎王龙巢穴

    在火山最深处的巢穴中，炎王龙正在沉睡。

最终决战

面对最终的威胁，所有力量汇聚于此

👑

最终任务：荒野的终结

最终任务
🎯 报酬：5000 ZENY⏱️ 限时：50分钟📍 地点：古代王座

📋 流程步骤

  1. 最终准备

    确保装备满强化，炼金全部带上。推荐装备：最高等级龙属性武器+全抗防具。

  2. 踏入王座

    最终BOSS煌黑龙在王座中等候。战斗分为两个阶段。

  3. 第一阶段

    煌黑龙使用龙属性吐息和翅膀攻击。注意躲避龙息的范围攻击。

  4. 第二阶段

    血量降至50%后，煌黑龙获得雷属性加持，攻击速度和范围大幅增加。

  5. 胜利

    击败煌黑龙后，游戏主线结束。但还有大量后续内容等待探索……

🐾 BOSS聚焦：煌黑龙

属性弱点冰 ❄️ → 雷 ⚡
高伤害部位头部、翼
阶段转换50%血量转雷属性
关键素材煌黑龙之鳞、煌黑龙之逆鳞
